# Material suplementar do TCC

**HIRAO, B. T.** *Adoção de sistemas de análise de desempenho de jogadores em clubes de futebol de diferentes portes: proposta de modelo de maturidade.* Trabalho de Conclusão de Curso (Engenharia de Produção) – Escola Politécnica, Universidade de São Paulo, São Paulo, 2026. Orientador: Prof. Dr. Luiz Fernando Cardoso dos Santos Durão.

Este repositório reúne o material suplementar citado nas Seções 4.3.2 e 4.4 e no Apêndice C do trabalho: o instrumento de codificação empregado na análise dos quatro casos (Sevilla FC, Sociedade Esportiva Palmeiras, Red Bull Bragantino e Coritiba Foot Ball Club).

## Conteúdo

| Arquivo | Conteúdo | Correspondência no trabalho |
|---|---|---|
| `planilha/TCC_material_suplementar.xlsx` | Planilha completa, com todas as abas abaixo e as contagens calculadas por fórmula | Seção 4.3.2 |
| `dados/1_livro_de_codigos.csv` | Livro de códigos: 12 subdimensões a priori e a categoria emergente Em1 | Apêndice B (Tabela 28) |
| `dados/2_rastreabilidade.csv` | Matriz de rastreabilidade: questões de cada roteiro que eliciam cada subdimensão | Seção 4.3.2; Tabela 7 |
| `dados/3_registro.csv` | Registro das 175 unidades de registro, com atributos, corroboração e memorandos de codificação | Apêndice C (Tabelas 29 a 32) |
| `dados/4_contagens.csv` | Contagens por caso e por subdimensão | Tabelas 13 e 16 |
| `dados/5_fontes_documentais.csv` | Fontes documentais referidas no registro, com endereço eletrônico | Tabela 33 |
| `dados/6_cronologia.csv` | Marcos de cada caso e registros não codificados | Seção 5.1 |

Os arquivos `.csv` podem ser lidos diretamente no navegador, nesta página do GitHub, sem necessidade de Excel.

## Notação

- **Casos:** SEV = Sevilla FC; PAL = Palmeiras; RBB = Red Bull Bragantino; CFC = Coritiba.
- **Questões:** Q = questão do roteiro do clube (Apêndice A); C = questão complementar; NP = sondagem não prevista; Abertura = fala anterior à primeira questão.
- **Fonte:** ENT = entrevista; ANX = resposta a questão complementar; DOC = documento.
- **Natureza:** CI = capacidade instalada; UD = uso decisório; CC = condição de contorno.
- **Sentido:** + facilitador; − barreira; 0 descritivo.
- **Força:** F1 convergente; F2 direta; F3 percepção; F4 frágil.
- **Corroboração:** C = corrobora; P = convergência parcial; V = verificação de consistência; E = delimita o escopo; T = data o evento de forma distinta.

## O que não está incluído

Gravações, transcrições e trechos literais das entrevistas não são publicados, em observância ao consentimento dos participantes, que autorizaram o uso restrito à finalidade acadêmica (Seção 4.4). Os trechos que fundamentam cada unidade de registro podem ser disponibilizados à banca examinadora mediante solicitação à autora.
